Closed finding 1 — P3: mobile glow vertical tap spacing uses the horizontal texel size.
cinema-renderer.ts line18 rotates uStep into the vertical axis, but line88 initializes uStep.x from 1.25/a.width. The mobile one-pass kernel therefore has vertical radius proportional to bloom height/width instead of matching the horizontal radius in pixels. Measured final targets: portrait98×152 -> 1.55× vertical radius; landscape159×85 -> 0.53×. Glow shape changes with device orientation. Use a separate vertical texel step based on a.height for mobile vertical taps. Desktop's second pass already uses height correctly.
Evidence: targeted-resize.json, shader lines18/88.
