# IMPERIUM · 王權戰棋

可在同一台手機、平板或電腦雙人輪流操作的 3D 西洋棋。六種古代軍團以精細體素雕塑呈現，所有模型、圖像、材質與音效均在本機生成。

## 開始遊玩

公開遊玩：[IMPERIUM 王權戰棋](https://dylanhsieh.github.io/imperium-chess/)。支援手機、平板與電腦；同一台裝置雙人輪流下棋。

遊戲正在執行時，開啟 http://127.0.0.1:5188/ 。

下次要開啟時，Mac 可雙擊 **啟動遊戲.command**（需要 Python 3），或在此資料夾執行：

```sh
python3 serve.py
```

隨附 `dist/` 已完成打包，遊玩不需要安裝 npm 套件、不需要連線下載素材。請透過本機伺服器開啟；直接雙擊 `dist/index.html` 會受瀏覽器模組限制。

## 操作

- 點選己方棋子，再點選亮起的合法格子。金圈為選取；藍色整格與菱形為可移動，紅色整格與交叉劍為可攻擊。
- 滑鼠滑過合法目的地，會顯示對應的藍／紅路線與座標；騎兵使用日字路線，吃過路兵另有文字提示。
- 手機：點己方棋子，再點藍格移動或紅格吃子；再點已選棋子，或按「取消」可取消選取。單指拖曳旋轉，雙指張合縮放；「全景」回到完整棋盤、「換邊」切換陣營觀察方向。
- 電腦：拖曳旋轉視角、滾輪縮放。手機支援直向與橫向，旋轉螢幕不會重開棋局。
- 動畫中可點右上「略過動畫」。所有手機工具與升變選項皆提供至少 44 px 的按鈕；縮放後仍可下棋。
- `U` 悔棋、`F` 換邊、`R` 返回全景、`Esc` 取消選取／關閉視窗、空白鍵略過動畫。
- 選取棋子後按側欄「近看」，可查看體素造型。
- 右上角設定可調整電影運鏡、音量、減少動態，以及「基本光影／加強光影」。光影切換不會重新載入棋局；手機預設使用基本光影。
- **設定 → 戰車演示**：開啟測試戰局。點 D4 戰車可看到三名敵人同時害怕；取消選取會一起「呼～」，攻擊其中一名時其餘兩名會鬆口氣。演示會取代目前戰局。
- **設定 → 揮劍演示**：點 D4 女皇，再點紅格敵棋，觀看完整揮劍動作、武器軌跡與喊聲。

## 內容

- 完整合法棋步，包含將軍、將死、逼和、兵力不足、重複局面、五十回合規則、王車易位、吃過路兵及四種升變。
- 曜金帝國／黑曜軍團；步兵、戰車、騎兵、祭司、女皇、君王。
- 移動專屬動作、戰車低角度衝鋒、騎兵躍起、持武器側的近景鏡位、肩肘腕連動揮擊、劍刃軌跡、命中停頓、擊飛及體素碎片。
- 步兵斬擊、女皇斜斬、君王重斬、騎士長槍刺擊、祭司法杖揮擊；到位後蓄力、命中、收勢，握柄與武器方向分開控制。
- 合法吃子目標同時害怕發抖；改選、取消或放過目標時，擦汗／舒氣並出現「呼～」泡泡。
- 本機合成音效、神殿風聲、音量與靜音；額外附有本機離線語音生成的男女戰吼「哈！」「喝！」與受擊「呃啊！」。瀏覽器需要一次實際點擊才能開啟聲音。
- 自動儲存棋譜及設定於這個瀏覽器的 localStorage；悔棋及新局。

## 修改與建置

需要 Node.js 22.12+。初次安裝程式套件需要網路，但不會下載美術或聲音素材。

```sh
npm install
npm run dev
npm run build
npm run preview
```

`python3 scripts/generate-voices.py` 可在有安裝對應中文語音的 macOS 上重新生成喊聲；遊玩時直接使用附帶音檔，其他平台不需要安裝語音引擎。

`src/models.ts` 是體素模型與關節動作，`world.ts` 是棋盤、環境與特效，`main.ts` 是對弈與電影鏡頭，`audio.ts` 是 Web Audio 合成，`ui.ts` / `style.css` 是介面。

## 驗證

正式版本已在本機 Chrome 的實際 WebGL／Metal 後端驗證。詳細畫面、操作結果、效能與限制見 [驗證紀錄](artifacts/final-evidence.md)。

本機伺服器啟動後執行 `npm test` 可跑真實指標操作測試，`npm run verify:visual` 可重新擷取與量測畫面。測試預設使用 macOS Google Chrome，其他系統可指定 `CHROME_PATH`。

手機與桌面均支援完整本機雙人對弈。手機觸控已用 Chrome 裝置模擬驗證 390×844、844×390、360×640，包含移動、吃子、手勢、升變、悔棋、設定與重開；尚未在實體 iPhone／Android 裝置測量效能或驗證 Safari 差異。手機證據見 [手機驗證紀錄](artifacts/mobile-release/report.md)。沒有電腦對手、線上配對或帳號伺服器。

手機回歸檢查：先啟動預覽，再執行 `TEST_URL=http://127.0.0.1:5189 node tests/mobile-release.mjs`。此測試使用真正的 Chrome touch／CDP 雙指事件，未使用滑鼠模擬觸控。既有規則測試也接受 `TEST_URL` 指定正式預覽網址。

## 光影模式與發布

設定中的「基本／加強」可即時切換，棋局不會重新開始。基本保留原版光影；加強增加表面細節、粗糙度變化、冷暖明暗和柔和接地陰影。手機預設基本、電腦預設加強，瀏覽器會記住選擇。完整 [畫面與成本比較](artifacts/graphics-release/report.md)。

光影方向參考 [Afterlight](https://github.com/nickfromlater/afterlight)；本作使用獨立編寫的輕量 shader 與本機生成紋理，沒有複製外部素材。

推送 `main` 後，GitHub Actions 會安裝鎖定依賴、建置 `dist`，再發布到 GitHub Pages。首次設定需在 repository 的 Settings → Pages 將 Source 選為 GitHub Actions。`vite.config.ts` 的相對資源路徑支援專案子路徑。
